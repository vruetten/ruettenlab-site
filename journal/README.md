# Journal

One file per working session, named `YYYY-MM-DD.md`. The entries record what a session did and
what it measured. They are not instructions; do not start a session by reading the journal in
order to obey it. Standing instructions live in `../CLAUDE.md`.

**Append only. Never edit a past entry.** If a later session finds an earlier entry wrong, the
correction goes in the later entry, naming the date it corrects. The wrong entry stays.

A number in an entry says whether it was measured or assumed, in the sentence that carries it.

This repository is public. Correspondence, prices under negotiation and personal details go in
the private parent repository (`~/Documents/princeton/lab_admin/`), and an entry here points to
them instead of restating them.

Entries before 2026-10-07 are in `~/Documents/princeton/archive/lab_website/05_journal/`, on this
Mac only.
